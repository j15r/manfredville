# Manfredville

Aufbau-Strategiespiel im Browser – ein Mix aus Anno (Produktionsketten), Die Siedler (Trägerlogistik über ein Straßennetz) und Age of Empires.

- **Spielen:** `manfredville.html` im Browser öffnen (Doppelklick genügt). Kein Build-Prozess, kein Server, keine externen Assets – Grafik (Canvas 2D) und Audio (Web Audio API) werden vollständig per Code erzeugt.
- **Entwicklungsstand:** siehe [`status.md`](status.md) – Konzept, Funktionsumfang, Architektur- und Technikhinweise sowie die Historie der Entwicklungsrunden.
